# 晚安小月亮（小米 / 安卓 9 以上）

倒计时到点后自动：暂停视频 → 返回 → 回到桌面 → 锁屏熄屏。适用于微信视频号、抖音等任何 App。

## 一、打包成 APK（二选一）

### 方法 A：用 GitHub 自动打包（推荐，不用装软件）
1. 在 GitHub 新建一个仓库，把本文件夹里**所有**文件上传（包括 `.github` 文件夹）
2. 打开仓库的 **Actions** 页面，等 “Build APK” 变成绿色 ✅（约 3～5 分钟）
3. 点进去，在最下面 Artifacts 里下载 `GoodNightMoon.apk`，解压得到 `GoodNightMoon.apk`

### 方法 B：用 Android Studio
1. 安装 Android Studio，File → Open 选本文件夹
2. 等它同步完成，菜单 Build → Build App Bundle(s)/APK(s) → Build APK(s)
3. 生成的文件在 `app/build/outputs/apk/debug/app-debug.apk`

## 二、发到她手机上安装
- 微信直接发 .apk 可能会被改名，可以压缩成 zip 再发，或者用 QQ / 数据线传
- 安装时小米会提示“未知来源/风险应用”，选“继续安装”

## 三、第一次使用要开的权限（小米）
1. 打开 App → 点“去开启权限” → **已下载的应用** → 晚安小月亮 → 打开
   - 如果开关是灰的、提示“受限设置”：去 设置 → 应用设置 → 晚安小月亮 → 右上角 ⋮ → **允许受限制的设置**，再回去开
2. 应用信息 → **省电策略 → 无限制**
3. 应用信息 → **自启动 → 打开**
4. 最近任务里把这个 App 下拉 **锁定**，防止被一键清理

## 四、用法
打开 App → 点 15 / 30 / 45 / 60 分钟或自定义 → 自动回到后台，直接去刷视频。
- 到点前 1 分钟会弹提示，想继续看就回 App 重新设
- 她自己按锁屏键，定时会自动取消
- 本 App 不读取屏幕内容、不联网
