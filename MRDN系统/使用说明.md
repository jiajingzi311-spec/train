# MRDN 系统 · 业务操作手册（桌面应用）

一个单机版「业务操作 SOP 工作台」：把网站操作拆成一条条「操作节点」，
每个节点记录 **输入（进来啥）/ 输出（出去啥）**，节点之间可以「引用上一节点的输出」
形成链路，还可以在节点上挂一个 Python 工具（exe）一键运行并查看日志。

## 一、怎么启动

**双击 `MRDN系统.exe`** 即可，无需安装 Python 或任何环境。

> 首次打开会自动生成 `data/` 和 `tools/` 目录，属正常现象。

## 二、文件夹说明

```
MRDN系统/                    ← 整个文件夹发给同事
├── MRDN系统.exe             ← 主程序，双击启动
├── tools/                   ← 放你的 Python 工具（.exe）
│   └── （把工具 exe 拖进来）
├── data/                    ← 你的数据（自动生成，别删）
│   ├── data.json            ← 节点配置（自动保存）
│   ├── 操作手册.xlsx        ← 全量 Excel 存档
│   ├── shots/               ← 贴图截图
│   └── 导出/                ← 手动导出的 Excel
└── _internal/               ← 程序依赖（勿动）
```

## 三、核心概念

- **流程**：一条完整业务线（如「订单数据导出」）。
- **节点**：流程里的一步操作。
- **输入 / 输出**：每个节点的入口条件（做这步前手里得有啥）和出口结果（做完得到啥）。
- **引用链路**：节点的「输入」可选「引用某节点的输出」，自动串成上下游箭头。

## 四、怎么用

### 录制节点
1. 点右上角「＋ 录制节点」，选流程、填名称/描述/输入/输出，保存即入册。
   - 输入可选「文字」或「引用某节点的输出」（形成上下游链路）。
   - 支持 **Ctrl+V 粘贴截图**（贴图存到 `data/shots/`）。
2. **挂 Python 工具**：节点可配置一个工具（下拉选择 `tools/` 里的 exe），
   点「▶ 运行工具」会真实执行该 exe，运行日志实时显示（日志不保存，仅临时查看）。

### 照着流程做
1. 首页点进某条流程，进入**横版流程条**视图：节点从左到右排成一排。
   - 🔵 **蓝色** = 已做完的节点
   - ⬇️ **箭头指向** = 当前这一步（进行中）
   - ⚪ **灰色** = 还没做的节点
2. 点任意节点，下方**操作台**会显示这一步的完整内容（怎么做、进来啥、出去啥、工具、截图）。
3. 做完一步，点「✅ 完成本步，下一步」，箭头自动移到下一格，当前节点变蓝。
4. 全部做完显示「🎉 流程已完成」；点「↺ 重置」可从头再来。

### 其他
- **搜索**：顶栏搜索框，按流程名快速定位。
- **打开目录**：顶栏「📁 数据」「🔧 工具」可直接打开对应文件夹。

## 五、数据保存

- 节点配置**自动保存**到 `data/data.json`（每次修改即写盘）。
- 顶栏「📥 导出 Excel」把全部节点导出成表格，存到 `data/导出/操作手册_日期.xlsx`。
- 运行日志**不保存**，只是运行时临时看。

## 六、打包发给同事

1. 把你要用的工具 exe 放进 `tools/` 文件夹；
2. 把整个 `MRDN系统` 文件夹（含 exe、tools、data）压缩发给同事；
3. 同事解压后**双击 `MRDN系统.exe`** 即用，工具路径自动识别，零环境依赖。

> 工具只在配置时存「文件名」，运行时自动从 `tools/` 目录拼接路径，
> 所以换电脑、换目录都不会失效。

## 七、常见问题

- **双击没反应 / 闪退**：确认系统已装 Edge WebView2 运行时（Win10/11 一般自带；若缺，到微软官网装 "WebView2 Runtime"）。
- **工具列表为空**：把工具 exe 放进 `tools/` 文件夹后，重新打开节点配置即可看到。
